# Stack Tecnológica

Registro centralizado das tecnologias, bibliotecas e versões adotadas no **CampusFlow**.

| Camada | Tecnologia | Versão | Propósito |
|---|---|---|---|
| Mobile (App) | React Native (Expo) | ~51.0.0 | Plataforma de desenvolvimento mobile multiplataforma |
| Linguagem | TypeScript | ~5.3.3 | Tipagem estática e segurança de código |
| Navegação | React Navigation (Stack + Bottom Tabs) | ^6.x | Gerenciamento de rotas e navegação por abas |
| Persistência Local | SQLite / Memory Storage | ~14.0.3 | Armazenamento 100% offline no dispositivo |
| Testes Unitários | Jest + ts-jest | ^29.x | Cobertura e validação das regras de negócio |
